# Contributing to OrynLauncher

Thank you for contributing to **OrynLauncher**! OrynLauncher is developed by the OrynLauncher team and community contributors.

## Before You Start

- Read the project README first.
- Keep changes focused on OrynLauncher.
- Test your changes before submitting them.
- Preserve required third-party licenses, copyright notices, and attribution.
- Do not remove or hide legally required upstream notices.

## What We Welcome

- 🐛 Bug fixes and stability improvements
- 🚀 New launcher features
- 🎨 UI/UX improvements
- ⚡ Performance improvements
- 📦 Mod, modpack, resource-pack, and shader improvements
- 📚 Documentation
- 🌍 Translations
- 🧪 Testing and crash reports

## Development

Use the **Orynlauncher-v5** branch for V5 development.

```bash
git clone https://github.com/Orynlauncher-Official/OrynLauncher2.git
cd OrynLauncher2
git checkout Orynlauncher-v5
```

Use the existing Gradle, Android, and project configuration. Avoid unnecessary rewrites of working launcher systems.

## Pull Requests

Before opening a pull request:

- [ ] The project builds successfully.
- [ ] The change was tested on Android where applicable.
- [ ] No unrelated files or systems were changed.
- [ ] No secrets, tokens, or private credentials were committed.
- [ ] Required license and copyright notices are preserved.
- [ ] The PR description clearly explains the change.

Use clear commit and PR titles, for example:

- `[FIX] Fix launcher startup crash`
- `[FEAT] Add Modrinth resource-pack support`

## Code Guidelines

- Follow the existing Java/Kotlin style.
- Use meaningful names.
- Keep changes maintainable and focused.
- Avoid introducing unnecessary dependencies.
- Preserve existing launcher functionality unless the change specifically requires modifying it.

## Reporting Bugs

Include:

- OrynLauncher version/build
- Android version
- Device model
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant logs or screenshots

## Upstream Attribution

OrynLauncher builds on open-source software, including work from **Zalith Launcher 2** and other upstream projects.
