## 🚀 About OrynLauncher

**OrynLauncher** is an Android launcher for **Minecraft: Java Edition**.

OrynLauncher is an independent community launcher project built with open-source components. Required upstream licenses and attribution are preserved in the repository.

OrynLauncher aims to provide:

- 🎮 Reliable Minecraft: Java Edition launching
- 👤 Microsoft and offline account support
- 📦 Minecraft version and instance management
- 🧩 Mod, modpack, resource-pack, and shader management
- 📁 File and instance management
- ⚙️ Launcher settings and customization
- 🚀 Performance-focused launcher features
- 🎨 OrynLauncher branding and UI
- 🔧 Crash and troubleshooting tools
- 💬 Discord community integration

## 📦 Building OrynLauncher

### Requirements

- Android Studio
- Android SDK
- JDK compatible with the project's Gradle configuration
- Git

### Clone

```bash
git clone https://github.com/Orynlauncher-Official/OrynLauncher2.git
cd OrynLauncher2
```

### V5

```bash
git checkout Orynlauncher-v5
```

Build using the Gradle configuration included in the repository.

For development, use the project's existing Gradle and Android configuration rather than replacing dependencies or modules unnecessarily.
